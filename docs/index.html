This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer.
To reach SAX, this page needs the small SAX-CE relay running on this computer (web pages can't connect to IRC by themselves). Download relay.mjs and run node relay.mjs (needs Node.js), or use start-bridge from the project. If Chrome asks to let this site access devices on your local network, allow it. Local test mode under Settings works without it.

Chrome is blocking this page from reaching the relay. Click the icon left of the address, open Site settings, set Local network access to Allow, then reload. Or use the copy the relay serves at http://localhost:8317/, which doesn't need this.

Run SAXCE on the calculator, plug it in, then click Connect (only needed once).
